Angular Alert (Toaster) Notifications

A high-performance Angular 22 notification system built with standalone components, reactive pub-sub state management via RxJS, modern @for control flow, and comprehensive Vitest unit testing.

Get Started GitHub Repository

Overview

The Angular Alert Notification library provides a clean, decoupled mechanism for triggering toast and banner notifications from any service, component, or routing event across your application. Built to operate in both single-target and multi-target topologies, it enables completely independent notification regions without tight component coupling.

Originally structured as an Angular 8 application using custom Webpack 4 loaders, this codebase has been modernized to Angular 22 with the latest esbuild + Vite application builder, strict TypeScript, and native Vitest testing.

Key Features

⚡ Standalone & Decoupled

Zero NgModule friction. Components import only what they need with maximum tree-shaking efficiency.

📡 Reactive Pub-Sub Architecture

Alerts are dispatched and subscribed via RxJS Subject and filtered observables, guaranteeing clean lifecycle handling.

🎯 Multi-Alert Target Routing

Support for multiple alert boxes on the same screen (e.g., column-specific alerts) targeted with unique IDs.

⏱️ Auto-Dismiss & Smooth Fade

Optional 3-second auto-close timers and CSS opacity transitions with strict timeout sanitation.

🔄 Route Change Persistence

Configure notifications to persist through navigation events using the keepAfterRouteChange flag.

🧪 100% Passing Vitest Suite

34 comprehensive unit tests covering services, components, timer events, and route navigation handlers.

Supported Alert Types

The library natively supports standard notification semantics with matching Bootstrap styling classes:

Type Enum Value Bootstrap Class Typical Use Case
Success AlertType.Success (0) alert alert-success Successful operations, save confirmations, account creation.
Error AlertType.Error (1) alert alert-danger Server faults, validation failures, authentication rejections.
Info AlertType.Info (2) alert alert-info System announcements, informational updates, status reminders.
Warning AlertType.Warning (3) alert alert-warning Impending session expirations, unsaved changes, rate limit notices.
